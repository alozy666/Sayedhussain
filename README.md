# مغامرة المستكشف علي في عالم الأرض المتغيرة

موقع تعليمي ثلاثي الأبعاد تفاعلي لدرس **«الأرض تتغير»** — مادة العلوم، **الصف الثالث الابتدائي**، منهج **مملكة البحرين**.

يدخل الطالب عالمًا كرتونيًا على شكل جزيرة، يستقبله فيه **المستكشف علي** (طفل بحريني بثوب أبيض وغترة بيضاء وعقال أسود)، ويرافقه عبر خمس محطات، ثم قاعة تحدٍّ ثلاثية الأبعاد، فنتيجة وشهادة إنجاز.

## التشغيل السريع دون برمجة

النسخة الجاهزة عبارة عن **ملف HTML واحد** يحتوي كل شيء (الرسومات والخط العربي والأصوات)، ويعمل **دون إنترنت ودون تثبيت**:

1. افتح الملف `offline/ali-explorer.html` (موجود في ملف ZIP المرفق) بالنقر المزدوج.
2. يُفضَّل فتحه في **Google Chrome** أو **Microsoft Edge** الحديثين.
3. اضغط **«ابدأ المغامرة»**.

يمكنك إنشاء هذا الملف بنفسك بالأمر `npm run build:single` (يظهر في `dist-single/index.html`).

## التشغيل للمطورين (Windows / macOS)

1. ثبّت **Node.js** الإصدار 20 أو أحدث (LTS) من [nodejs.org](https://nodejs.org).
2. افتح «موجه الأوامر» (Windows: PowerShell أو Terminal) أو «Terminal» (macOS) داخل مجلد المشروع.
3. نفّذ:

```bash
npm install        # تثبيت المكتبات (مرة واحدة)
npm run dev        # تشغيل خادم التطوير
```

4. افتح الرابط الذي يظهر (عادةً `http://localhost:5173`).

أوامر أخرى:

| الأمر | الوظيفة |
| --- | --- |
| `npm run build` | بناء نسخة النشر في مجلد `dist/` |
| `npm run build:single` | بناء ملف HTML واحد يعمل دون خادم في `dist-single/` |
| `npm run preview` | معاينة نسخة `dist/` محليًا |
| `npm test` | اختبارات الوحدة لنظام التصحيح والدرجات |
| `npm run test:e2e` | اختبار شامل يلعب المغامرة كاملة آليًا (انظر قسم الاختبارات) |

## النشر على استضافة ويب

بعد `npm run build` ارفع **محتويات** مجلد `dist/` إلى أي استضافة ملفات ثابتة؛ الروابط داخل الموقع نسبية فيعمل من أي مسار:

- **GitHub Pages (مفعّل لهذا المستودع):** الموقع يُخدم من فرع `gh-pages`. سير العمل `.github/workflows/pages.yml` يشغّل الاختبارات ثم يبني الموقع وينشره إلى `gh-pages` تلقائيًا عند كل دفع إلى الفرع الرئيسي للمستودع، فتظهر التعديلات على الرابط خلال دقيقة أو دقيقتين. يمكن تشغيله يدويًا من تبويب *Actions*.
- **Netlify:** اسحب مجلد `dist/` وأفلته في صفحة [app.netlify.com/drop](https://app.netlify.com/drop).
- **Vercel / خادم المدرسة:** ارفع محتويات `dist/` كموقع ثابت.

> ملاحظة: وضع VR يتطلب أن يُفتح الموقع عبر **HTTPS** (أو `localhost`)، وهذا متوفر تلقائيًا في الاستضافات المذكورة.

## طريقة اللعب والتحكم

كل الأنشطة تعمل **بالفأرة وحدها**، ولوحة المفاتيح اختيارية:

| التحكم | الوظيفة |
| --- | --- |
| سحب الفأرة (الزر الأيسر) | تدوير زاوية الرؤية حول المحطة ضمن حدود مريحة |
| عجلة الفأرة | التقريب والإبعاد ضمن حدود مناسبة |
| النقر بالزر الأيسر | الأزرار ثلاثية الأبعاد، بطاقات الإجابات، أزرار الواجهة |
| `W` `A` `S` `D` أو الأسهم | تحريك بسيط للرؤية (اختياري) |
| `R` أو زر «ضبط الرؤية» | إعادة زاوية الرؤية المناسبة للمحطة |
| `M` أو زر «الخريطة» | خريطة الجزيرة (لقطة علوية حقيقية) والانتقال بين المحطات المفتوحة |
| `1` `2` `3` | اختيار الإجابة أ / ب / ج في الأسئلة |
| `Enter` | الزر الرئيسي (شاهد / التالي / السؤال التالي) |
| `H` | تعليمات اللعب |

- الكاميرا **لا تهتز أبدًا** (حتى في مشهد الزلزال تهتز عناصر المشهد فقط)، والانتقالات بطيئة وسلسة.
- يعمل الموقع على أحجام الشاشات المختلفة (مصمم أساسًا لـ 1920×1080، ويتكيف مع الحواسيب المحمولة والأجهزة اللوحية).

## مكونات التجربة

| المرحلة | ما يحدث |
| --- | --- |
| **الصفحة الرئيسية** | بوابة مغامرات بلافتة «مغامرة المستكشف علي — لنكتشف كيف تتغير الأرض!»، علي يلوّح ويرحب، وأزرار: ابدأ المغامرة، طريقة اللعب، الصوت، وضع VR |
| **1. الزلزال** | طريق ومنزل وأشجار وصخور وجبال بعيدة؛ اهتزاز مُخمَّد لعناصر المشهد ثم تشقق يبقى ظاهرًا. لوحة: «اهتزاز مفاجئ في القشرة الأرضية.» مع ملاحظة أن التشققات أثر محتمل |
| **2. البركان** | بركان بفوهة واضحة؛ الحمم تعلو في الفوهة ثم تتدفق ببطء على الجانب مع دخان خفيف وتوهج معتدل، دون انفجارات |
| **3. التجوية** | صخرة تظهر فيها شقوق ثم تتفتت قطع منها **وتبقى بجانبها**، مع وسم «محاكاة مسرّعة». يليها **السؤال التدريبي الأول** |
| **4. التعرية** | ماء يجري في مجرى من مرتفع إلى منخفض وينقل التربة وفتات الصخور (مع أسهم الاتجاه) لتتراكم في المنخفض. لوحة مقارنة مصورة: «التجوية = تفتت الصخور / التعرية = انتقال الفتات». يليها **السؤال التدريبي الثاني** |
| **5. تغييرات الإنسان** | حفارة صفراء تزيل التلال وتمهد الأرض ثم يتكوّن طريق؛ وسم «قبل العمل / بعد العمل» وزر «قبل / بعد» للمقارنة |
| **قاعة التحدي** | بوابة «تحدي المستكشف علي» ثم قاعة دائرية بلوحة سؤال عائمة وثلاث بطاقات **مصورة من نماذج المحطات نفسها**، ومؤشر «السؤال x من 5» |
| **النتائج** | منصة احتفال: الدرجة والنسبة وخمس نجوم ورسالة النجاح أو التشجيع، وعند 80% فأكثر **شهادة المستكشف الصغير** (تنزيل PNG أو طباعة، مع حقل اسم اختياري لا يُحفظ) وأزرار: إعادة التحدي، مراجعة المحطات، العودة إلى البداية |

**قواعد التقويم:** 5 أسئلة × نقطة واحدة؛ تُحتسب **الإجابة الأولى فقط**؛ لا يُكشف أي تلميح قبل الاختيار؛ بعد الإجابة الخاطئة يظهر تصحيح لطيف ثم تُبرز الإجابة الصحيحة؛ لا يُنتقل للسؤال التالي إلا بالضغط على الزر؛ **يتحقق الهدف عند 4/5 (80%) فأكثر فقط**.

**الصوت:** المؤثرات الصوتية مولّدة برمجيًا. شرح علي الصوتي يستخدم قراءة النص الآلية في المتصفح إن توفر صوت عربي على الجهاز (Microsoft Edge يوفر أصواتًا عربية جيدة منها صوت بحريني)، ويظهر زر «استمع لعلي» عندها؛ وإن لم يتوفر يبقى النص ظاهرًا دائمًا.

**الحفظ:** تقدم الطالب يُحفظ خلال الجلسة (`sessionStorage`) فيمكن تحديث الصفحة والمتابعة، ويظهر خيار «ابدأ مغامرة جديدة من الصفر» لطالب جديد على الجهاز نفسه.

## لوحة المعلم

زر صغير هادئ أعلى يسار الشاشة (أيقونة اللوح). يعرض:

- آخر محاولة: الدرجة، النسبة، عدد الإجابات الصحيحة والخاطئة، حالة تحقق الهدف.
- تفاصيل كل سؤال والمفهوم الذي يقيسه، مع **حالات الخلط** (مثل: «اختار التجوية بدل التعرية»).
- سجل كل المحاولات على هذا الجهاز، وعدد مرات الخطأ في كل مفهوم، وعدد محاولات السؤالين التدريبيين.
- **طباعة النتيجة**، و**تنزيل CSV** (UTF-8 يُفتح بالعربية في Excel)، و**نسخ النتائج** للصقها مباشرة في Excel أو Google Sheets، ومسح السجل (بتأكيد داخل الصفحة).

البيانات محفوظة محليًا في متصفح الجهاز فقط (`localStorage`)، **دون أسماء أو أي بيانات شخصية**.

## وضع الواقع الافتراضي VR والسلامة

- الموقع مبني على **WebXR**: عند فتحه من متصفح يدعم VR يظهر خيار «دخول وضع VR». كل الأزرار والأسئلة واللوحات ثلاثية الأبعاد فتعمل داخل النظارة، ويُختار بزناد وحدة التحكم، والتنقل بين المحطات بالتلاشي لراحة المستخدم، والتقدم والنتائج مشتركة بين الوضعين.
- **الأجهزة المتوقع توافقها** (لم تُختبر على نظارة حقيقية أثناء التطوير): متصفح Meta Quest (Quest 2 / 3 / 3S / Pro)، متصفح Pico، وChrome/Edge على حاسوب متصل بنظارة PC VR تدعم WebXR (مثل SteamVR أو Windows Mixed Reality). لا نَدّعي دعم جميع النظارات.
- **العمر والسلامة:** تشترط Meta لاستخدام Quest عمر **10 سنوات فأكثر** بحساب يديره ولي الأمر للأعمار 10–12، وتوصي Pico بعدم استخدام نظاراتها لمن هم **12 سنة فأقل**. تلاميذ الصف الثالث غالبًا في عمر 8–9 سنوات، لذلك **نوصي بأن يستخدم الطلاب نسخة الحاسوب**، وأن يقتصر وضع VR على العرض بإشراف المعلم ووفق سياسة الشركة المصنعة والمدرسة، في مكان خالٍ من العوائق، وبجلسات قصيرة (10–15 دقيقة). راجع دائمًا الإرشادات الحالية للشركة المصنعة.

## الاختبارات

```bash
npm test            # 17 اختبار وحدة (vitest)
npm run test:e2e    # يبني الموقع ثم يلعب المغامرة كاملة في Chromium (65 فحصًا)
```

- **اختبارات الوحدة** (`tests/quiz.test.js`): صحة الأسئلة والإجابات، حالات الدرجات 5/5=100%، 4/5=80%، 3/5=60%، 2/5=40%، 1/5=20%، 0/5=0% وتحقق الهدف عند 80% فأكثر فقط، احتساب الإجابة الأولى فقط، التصفير عند الإعادة، المفاهيم الخاطئة، وملف CSV.
- **الاختبار الشامل** (`tests/e2e/playthrough.mjs`): نقرات فأرة حقيقية على الأزرار والبطاقات ثلاثية الأبعاد عبر المحطات الخمس، وإعادة المشاهدة، والتدريبين (إجابة خاطئة ثم صحيحة)، وزر قبل/بعد، ثم التحدي بأربعة سيناريوهات (4/5، 3/5، 5/5، 0/5) والتحقق من النسبة والشهادة، وتنزيل الشهادة، ولوحة المعلم وملف CSV، والخريطة، وحفظ التقدم بعد التحديث، وعدم وجود أخطاء في وحدة التحكم. تُحفظ لقطات الشاشة في `test-results/`.
- يحتاج الاختبار الشامل متصفح Chromium: حدّد مساره في المتغير `CHROMIUM_PATH`، أو ثبّته بالأمر `npx playwright-core install chromium`.

## هيكل المشروع

```
index.html                 الصفحة (عربية RTL) + شاشة التحميل + شاشة الخطأ
src/main.js                الإقلاع: تحميل الخط، بناء العالم، المحطات، القاعة، الحلقة الرئيسية
src/content/               النصوص والأسئلة (قابلة للتعديل)
src/app/                   Game.js (آلة الحالات والتنقل)، quiz.js (التصحيح)، progress.js، teacherStore.js
src/engine/                الكاميرا، التفاعل بالفأرة وVR، الصوت، القراءة الآلية، WebXR، المؤقتات
src/world/                 الجزيرة والسماء والماء والنباتات والبوابة ولوحة الألوان
src/character/Ali.js       شخصية المستكشف علي وحركاته
src/stations/              قاعدة المحطة + نماذج الظواهر الخمس (models/)
src/challenge/             قاعة التحدي، منطقة النتائج، الشهادة، الصور المصغرة
src/ui3d/                  لوحات وأزرار وبطاقات وفقاعة كلام ثلاثية الأبعاد بنص عربي
src/hud/                   واجهة الحاسوب: الشريط، الخريطة، التعليمات، لوحة المعلم
tests/                     اختبارات الوحدة والاختبار الشامل
```

**قرارات تقنية:** Vite + JavaScript + Three.js. كل المجسمات (علي، الأشجار والنخيل، البركان، الحفارة…) مبنية برمجيًا بأسلوب كرتوني، فلا توجد ملفات GLB أو صور يمكن أن تكون مفقودة، ويمكن لاحقًا استبدال أي مجسم بملف GLB عبر `GLTFLoader` دون تغيير المنطق. النص العربي على اللوحات ثلاثية الأبعاد يُرسم عبر Canvas فيتشكّل ويُعرض من اليمين لليسار بشكل صحيح. صور أسئلة التحدي تُرسم عند التحميل من نماذج المحطات نفسها، فتطابق ما شاهده الطالب.

## المتطلبات والقيود المعروفة

- يتطلب متصفحًا يدعم **WebGL 2** (Chrome وEdge وFirefox وSafari الحديثة). تظهر رسالة واضحة إذا لم يكن مدعومًا أو إذا فشل تحميل أي جزء.
- الأداء: يخفض الموقع دقة الرسم تلقائيًا على الأجهزة البطيئة، ويخفف الرسم عند فتح النوافذ.
- **وضع VR لم يُختبر على نظارة حقيقية** (بيئة التطوير لا تحتوي نظارة)؛ مسار الكود مبني على معيار WebXR في Three.js.
- **جودة الصوت العربي** تعتمد على الأصوات المثبتة في نظام التشغيل/المتصفح؛ بعض المتصفحات (مثل Chrome على Linux) لا توفر صوتًا عربيًا، فيبقى النص فقط.
- بيانات لوحة المعلم محلية لكل جهاز ومتصفح، ولا تُزامَن بين الأجهزة.
- عند عرض الموقع داخل إطار claude.ai للمعاينة: التنزيل يمر عبر نافذة تأكيد من claude.ai، والطباعة غير متاحة هناك (استخدم «نسخ النتائج» أو افتح الموقع من استضافته العادية للطباعة)، ووضع VR غير متاح داخل الإطار.
